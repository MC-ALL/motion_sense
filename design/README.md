# 设计资料

本目录存放 `motion_sense` 的设计文档，只负责说明系统边界、接口契约、当前进展与专项草案，不承担部署手册职责。

## 目录分工

- `00-03`：设备侧早期设计与历史资料；当前已标记为过时，除非明确需要追溯，否则不作为当前实现依据。
- `04-网关端.md`：网关职责、边缘规则、批量上报、命令链路与当前限制。
- `05-后台端.md`：后台领域边界、数据模型、实时链路、AI 基线与权限模型。
- `06-网页端.md`：网页端页面结构、状态模型、权限边界与接入规范。
- `07-通讯接口定义.md`：唯一接口契约来源，定义 BLE、MQTT、REST 与 WebSocket 稳定边界。
- `08-开发排期.md`：当前进展、验证状态、后续工作计划与历史阶段摘要。
- `09-运维观测端.md`：运维聚合边界、汇聚模型、鉴权关系与当前限制。
- `10-AI前端接入草案.md`：AI 前端交互的当前落地范围与后续演进草案。

## 使用要求

- 设计文档只写稳定边界、当前真实状态和明确的后续计划，不把运行手册、脚本清单和历史流水混入模块设计文档。
- 契约变更时，优先更新 `07-通讯接口定义.md`。
- 实现变化涉及 `04/05/06/09` 时，同时回查对应设计文档与 `08-开发排期.md`。
- 部署、起停、验收与排障说明统一放在 `deployment/` 与各模块 `README.md`。
