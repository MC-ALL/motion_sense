# 设计资料

本目录存放 `motion_sense` 的设计文档，不承担部署说明或运行手册职责。

## 目录功能

- 记录系统总览、模块边界、接口契约与开发排期。
- 为 `04/05/06/09` 的实现、联调与验收提供统一口径。
- 保存 AI 前端接入草案等仍处于设计阶段、但需要长期维护的资料。

## 目录结构

- `00-系统总览.md`：系统级目标、角色与跨模块链路。
- `01-手环端.md`、`02-器材端.md`、`03-环境端.md`：设备侧设计说明。
- `04-网关端.md`：MQTT 接入、规则引擎、缓冲与上报。
- `05-后台端.md`：业务 API、存储、鉴权与 AI 基线。
- `06-网页端.md`：页面、状态管理、运行时配置与权限边界。
- `07-通讯接口定义.md`：REST、WebSocket、MQTT topic 与 payload 契约。
- `08-开发排期.md`：当前进展、阶段结论与后续工作计划。
- `09-运维观测端.md`：运维聚合接口与健康模型。
- `10-AI前端接入草案.md`：AI 页面交互与后续接入草案。

## 使用要求

- 设计文档应描述“稳定边界”和“当前真实状态”，不要把未实现内容写成已实现。
- 实现发生变更时，优先同步对应模块 README，再回写本目录中的设计文件。
- 契约变更时，以 `07-通讯接口定义.md` 为核心同步点。
