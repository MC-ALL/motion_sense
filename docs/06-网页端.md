# 06 — 网页端

## 定位

面向健身房管理员、教师和学生的 Web 可视化平台，提供实时数据仪表盘、历史数据查询、告警管理和运维健康视图。业务数据通过后台端获取，基础设施健康视图通过独立运维观测端获取。

---

| 层次 | 选型 |
|------|------|

## 主要页面

### 1. 实时仪表盘

- 所有业务实时数据通过后台 `WS /api/ws` 更新。
- P0 告警以高优先级通知弹出，P1 告警进入告警列表。
- 图表采用滑动窗口，前端仅保留最近 200 个点。

### 2. 器材管理

- 器材列表、在线状态、当前绑定手环。
- 单台器材详情展示实时功率、累计能耗和历史曲线。

### 3. 环境质量

- 区域环境节点实时卡片。
- 历史趋势图支持 `1h / 6h / 24h / 7d`。
- 支持查看超标记录与聚合统计。

### 4. AI 分析报告

- 接口位置已预留，当前仍未实现。
- 页面设计保留入口，但不纳入当前开发重点。

### 5. 告警管理

- 支持按 `level`、设备、确认状态筛选。
- 支持单条确认与批量确认。

### 6. 用户管理

- 管理员视角的用户、角色、设备注册管理。
- 已接入后台 `GET/POST/PATCH/DELETE /api/v1/users`，提供管理员用户列表、创建、改角色/密码、删除。

### 7. 系统健康中心

用于查看网关、后台及其关键组件的在线与健康状态。

页面建议布局：

```text
┌──────────────────────────────────────────────────────────────┐
│ [模块总数] [健康模块] [降级模块] [离线模块]                  │
├──────────────────────────────────────────────────────────────┤
│ gateway/gw-001   healthy   更新时间: 09:00:00               │
│  - gateway_api        healthy   8ms                         │
│  - edge_processor     healthy   4ms                         │
│  - mqtt_broker        healthy   3ms                         │
│  - local_timeseries   degraded  120ms                       │
├──────────────────────────────────────────────────────────────┤
│ backend/api-main offline   更新时间: 08:59:30               │
│  - api_service        offline   timeout                     │
└──────────────────────────────────────────────────────────────┘
```

- 汇总卡片展示健康、降级、离线模块数量。
- 模块列表展示整体状态、最近上报时间、异常组件数。
- 详情展示组件状态、检查时间、延迟、异常详情。
- 当前设计默认优先使用 REST 轮询：
  - `GET /api/v1/ops/health`
  - `GET /api/v1/ops/health/{module_id}`
  - `GET /api/v1/ops/alerts`
  - `PATCH /api/v1/ops/alerts/{id}/close`
  - `GET /api/v1/ops/stats`
- 若需要实时刷新，可接入 `WS /api/ws/ops`。

## 与后台与运维端连接规范

### 业务后台

- REST API：`Authorization: Bearer {jwt}`
- WebSocket：`wss://{host}/api/ws?token={jwt}`
- 断线后指数退避重连（`1s -> 2s -> 4s`，上限 `30s`）
- 当前前端已支持：
  - 登录：`POST /api/v1/auth/login`
  - Token 刷新：遇到 `401` 时调用 `POST /api/v1/auth/refresh`
  - 退出：`POST /api/v1/auth/logout`
  - 运行时注入 `backend_base_url`、`backend_ws_url`

### 运维观测端

- REST API：`https://{host}/api/v1/ops/*`
- WebSocket：`wss://{host}/api/ws/ops`
- 健康中心不直接访问数据库，也不直连网关或后台私有端口。

完整契约见 [07-通讯接口定义.md](./07-通讯接口定义.md)。

## 部署

前端构建产物 `dist/` 由 Nginx 静态托管：

- `GET /` → React SPA
- `GET /api/*` → 代理至后台业务 API 或运维观测 API
- WebSocket Upgrade 由 Nginx 透传
