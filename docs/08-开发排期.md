# 08 — 开发排期（4 人小组）

## 团队构成与阶段分工

项目分三个阶段推进，团队成员随进度转换职责：

| 成员 | 专业方向 | Phase 1（S1-S3） | Phase 2（S4） | Phase 3（S5） |
|------|---------|------------------|---------------|---------------|
| A | 嵌入式 | 手环端 | 前端集成 | 部署调试 |
| B | 嵌入式 | 器材端 | 前端集成 | 部署调试 |
| C | 嵌入式 | 环境端 | 嵌入式测试 | 系统集成测试 |
| D | 边缘 / 后台 | 网关端 + 后台端 | 运维观测端 + 后台完善 | 系统集成测试 |

---

## 优先级定义

| 级别 | 含义 |
|------|------|
| P0 | 关键路径，阻塞其他模块，必须按时完成 |
| P1 | 核心功能，影响演示和验收 |
| P2 | 重要功能，在 P1 完成后迭代 |
| P3 | 增强功能，时间允许则实现 |

---

## 总体里程碑

```text
Sprint 1   设备 Bring-up + 基础设施
Sprint 2   核心传感器 + 数据链路打通
Sprint 3   子系统联调 + 嵌入式测试
────────── 里程碑 M1：数据可从设备端流入数据库 ──────────
Sprint 4   基础功能完善 + 运维观测接入
────────── 里程碑 M2：端到端演示可运行 ──────────────────
Sprint 5   全链路测试 + 部署 + 收尾
────────── 里程碑 M3：系统交付 ───────────────────────────
```
